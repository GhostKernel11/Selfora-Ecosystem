# Academic Ecosystem — Phase 20

Production-focused academic platform with Node.js, Express, SQLite, authentication, community features, real-time events, security controls, backups, deployment tooling, feedback, and performance observability.

## Start
```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Phase 20 checks
```bash
npm run phase19:check
npm run check
npm test
```

## Performance report
```bash
npm run performance:report
```

The production deployment is configured separately through the Render deployment workflow and environment variables documented in `DEPLOYMENT.md`.
